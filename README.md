## 🗂️ 项目结构

```
负责人AI/
├── index.html                # 📄 作品集入口（重定向 → leader-ai/index.html）
├── leader-ai/                # 📁 作品集与分析报告
│   ├── index.html            #    作品集首页（卡片式作业列表）
```
